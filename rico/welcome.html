Rico is in. 🐕

Name it and he brings back the right one. Three snippets are already waiting so there is something to try.

  1. Open Gmail and start a reply Rico only wakes up inside a compose window.
  2. Press ⌘⇧K The palette opens over the compose box.
  3. Type a few letters, press Enter The snippet lands where your cursor was.

Not ⌘K — Gmail already uses that for Insert Link inside a compose window, and Chrome reserves it for the address bar. You can switch Rico to ⌘K anyway from Settings if you never insert links.
