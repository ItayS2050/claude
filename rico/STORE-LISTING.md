## Full description

```
Rico was a border collie who knew two hundred words. Tell him the name of a
thing and he came back with the right one.

This does that with your email templates.

Gmail's Templates feature is three clicks deep in a menu and shows you a flat
list. Past ten templates you stop being able to find the one you want. Past
twenty, you stop using the feature. Rico is a search box for them.

Press Ctrl+Shift+K (Cmd+Shift+K on a Mac) inside any Gmail compose window.
Type a few letters. Press Enter. The snippet lands where your cursor was.
About two seconds, no mouse, no menu.


HOW IT WORKS

• Fuzzy search on titles — type "fo" to find "Follow up", and watch it rank
  above the other things that happen to contain an f and an o.
• Literal search inside the text, for the snippet whose name you have
  forgotten. Type "refund window" and it finds the one that says it.
• Arrow keys and Enter. Esc to back out. Your hands stay where they were.
• {FirstName} fills itself from whoever is in the To: field.
• Any other {Token} you invent — {Company}, {Invoice} — asks you to fill it
  before it inserts, so no half-finished "Hi {FirstName}" ever goes out.
• Line breaks and paragraphs come through intact, and Gmail's autosave picks
  the text up as though you typed it.


IT NOTICES WHAT YOU KEEP RETYPING

Write the same paragraph twice and Rico offers to keep it as a snippet, with a
title and a tag already filled in. It appears after the message has sent, never
before — and "Never" on any particular paragraph means never.

This does not mean Rico keeps your mail. It stores a one-way hash of each
paragraph you send and nothing else. A hash cannot be turned back into what you
wrote, and Rico never needed the old copy: when it recognises a repeat, the
paragraph is already on your screen. Your signature and the quoted thread are
stripped before anything is hashed. The whole feature has an off switch.


PRICING — PLEASE READ BEFORE INSTALLING

Free forever:
• 10 snippets
• The full palette, search, and keyboard navigation
• Manual variable fill

Rico Pro — $24, paid once. Not a subscription:
• Unlimited snippets
• {FirstName} fills automatically from the To: field
• Snippet folders
• Import and export as JSON

You pay once and that is the end of it. No monthly charge, no renewal, no card
on file with us — payments run through ExtensionPay and no card details ever
touch the extension.

The free tier limits how many snippets you can CREATE. It never limits using
the ones you have. If you are sitting on forty snippets from before, all forty
keep working.


PRIVACY

Rico has no server, no account, and no analytics. Your snippets are stored in
your own browser and carried between your machines by Chrome's own sync if you
have it turned on. Rico reads the compose window you are typing in — inserting
text at your cursor is not possible otherwise — and reads the To: field to fill
{FirstName}. Neither is stored or sent anywhere. It never touches your inbox,
your sent mail, or any thread you are not composing in.

The only permission Rico asks for is storage.


WHAT RICO DOES NOT DO

It works on Gmail. Not Outlook, not Superhuman, not LinkedIn. It does not
generate text with AI, does not share snippets with a team, and does not read
your mail. One thing, done quickly.


A NOTE ON THE SHORTCUT

Ctrl+K is already Gmail's Insert Link shortcut inside a compose window, and
Chrome reserves it for the address bar — so Rico stays off it by default and
uses Ctrl+Shift+K instead. If you never insert links, you can switch Rico to
Ctrl+K in Settings. The shortcut is yours to choose either way.
```

## Permission justifications

The review form asks for one per permission. These are written to be pasted as-is.

**`storage`**
> Snippets and settings are saved in the user's browser using chrome.storage.
> This is the only place Rico keeps data; there is no server.

**Host permission `https://extensionpay.com/*`**
> Required by ExtensionPay, the payment processor, to check whether the user has
> purchased the one-time Pro upgrade. No user content is sent; the request
> returns a paid/unpaid flag only.

**Content script on `https://mail.google.com/*`**
> Rico's entire function is inserting the user's own saved text into a Gmail
> compose window. It reads the compose box to find the cursor position and reads
> the To: field to substitute the recipient's first name. Nothing read from the
> page is transmitted anywhere.

**Single purpose**
> Inserting the user's saved text snippets into a Gmail compose window from a
> keyboard-driven search palette.

**Limited Use disclosure**
> Rico accesses the content of a Gmail compose window solely to insert the
> user's own saved text at the cursor and to read the recipient's name for
> variable substitution. It does not collect, transmit, or store message
> content, and does not use it for advertising, profiling, or model training.
> All processing happens locally in the browser.

### How the screenshots are made, and the one caveat

`make-store-assets.mjs` runs Chromium with the real extension loaded. The
palette, the token prompt, the suggestion card and the popup in these images are
all the real thing, photographed — if the UI changes, rerunning the script
changes the shots with it.

**Gmail cannot be signed into from a build script.** So the page around the
compose window is a fixture (`gmail-fixture.html`) served in place of
mail.google.com by a request intercept. The URL is real, so the content script
injects for real and its selectors run against a DOM shaped like Gmail's — but
Gmail's own sidebar, thread and colours are reconstructed. That is fine for
showing what Rico does. It would not be fine for claiming anything about Gmail,
and no shot should be captioned as if it were.
