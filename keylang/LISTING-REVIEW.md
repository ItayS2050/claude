# Kiko — store listing review: Ukrainian, Greek, Arabic

Two strings per language: the name shown in the Chrome Web Store, and the
one-line description under it. These are what a searcher in that language
sees before they see anything else.

I wrote them. Nobody who speaks these languages has read them. The Hebrew
went through two rounds of native corrections before it was right, so treat
these as drafts.

## Ukrainian (`uk`)

**Name** — 39/75 characters
> Kiko – виправлення розкладки клавіатури

**Description** — 126/132 characters
> Не та розкладка? Kiko знайде і одним кліком виправить текст українською, івритом, російською, корейською, грецькою, арабською.
