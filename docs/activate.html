Thanks — let's switch it on.

Takes about twenty seconds. Your licence key is in the confirmation you just saw, and in your email.

  1. Install Kiko, if you haven't yet

    Skip this if it's already in your toolbar. Get it from the Chrome Web Store →

  2. Open the Kiko popup

    Click the Kiko icon in your Chrome toolbar. Don't see it? Click the puzzle-piece icon and pin Kiko.

  3. Paste your key

    Drop it into the box marked Already paid? Paste licence key and press Activate.

That's it. The banner turns green and every language stays unlocked. Nothing to restart, no account to create, and your learned words are exactly where you left them.
Using more than one computer? Each device needs its own activation. If you run out, email us and we'll sort it.
