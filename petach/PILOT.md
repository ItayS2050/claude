# פתח · מדריך לפיילוט

## להעלות לאוויר ב-Netlify (פעם אחת, כ-10 דקות)

הדרך המומלצת היא לחבר את Netlify ל-GitHub. ככה כל עדכון שנדחף לענף עולה לאתר אוטומטית.

1. נכנסים ל-https://app.netlify.com ונרשמים עם חשבון ה-GitHub.
2. בוחרים **Add new site → Import an existing project → GitHub**, ומאשרים ל-Netlify גישה למאגר `itays2050/claude`.
3. בוחרים את המאגר `claude`. בשדה **Branch to deploy** בוחרים את `claude/small-business-construction-system-i455s7` (או את `main`, אחרי שממזגים אליו).
4. את שאר ההגדרות לא צריך למלא. הקובץ `netlify.toml` בשורש המאגר כבר אומר ל-Netlify לפרסם את `petach/doors` בלי build.
5. לוחצים **Deploy**. אחרי כדקה מתקבלת כתובת כמו `something-123.netlify.app`.
6. ב-**Site configuration → Change site name** משנים את השם ל-`petach` (או לשם פנוי אחר). הכתובת תהיה `petach.netlify.app`.

**חלופה בלי GitHub:** מחלצים את הקובץ `petach-pilot.zip` וגוררים את התיקייה `doors` ל-https://app.netlify.com/drop. בחלופה הזו כל עדכון דורש לגרור שוב.

## להתקין בטאבלט של החנות

1. פותחים את הכתובת ב-Chrome (אנדרואיד) או ב-Safari (אייפד).
2. בתפריט בוחרים **הוספה למסך הבית** / **Add to Home Screen**. מקבלים אייקון "פתח" שנפתח כמו אפליקציה.
3. אחרי פתיחה ראשונה עם אינטרנט, האפליקציה עובדת גם בלי חיבור, כולל הקטלוג והתמונות.

## הגדרה ראשונה בחנות (כ-15 דקות)

1. בלשונית **מחירון** ממלאים את פרטי העסק: שם, טלפון, כתובת וח.פ., מע״מ, מחירי התקנה ומקדמה.
2. לוחצים **הורדת המחירון לאקסל**. בעל החנות מעדכן את עמודת "מחיר" ולא נוגע בעמודת "קוד".
3. לוחצים **העלאת מחירון מעודכן** ובוחרים את הקובץ. האפליקציה מראה כמה מחירים השתנו.
4. עושים הצעה אחת לדוגמה מתחילתה ועד סופה: צילום פתח, בחירת דלת, הוספה להצעה, חתימה ושליחה בוואטסאפ.

## בשגרה

- **שמירת הצעות:** כל הצעה נשמרת אוטומטית ברשימת **הצעות** בלשונית "הצעת מחיר". אפשר לחזור לכל הצעה, והחתימה נשמרת איתה.
- **גיבוי:** הנתונים נשמרים **רק בטאבלט**. פעם בשבוע לוחצים **הורדת גיבוי מלא** ושומרים את הקובץ בדרייב או במייל. בטאבלט חדש או אחרי ניקוי הדפדפן לוחצים **שחזור מגיבוי**.
- **שינוי מחירים:** אפשר לערוך מחיר ישירות בטבלה, או שוב דרך אקסל.

## מה למדוד בשבועיים של הפיילוט

| מדד | איך יודעים |
|---|---|
| כמה הצעות הופקו | רשימת ההצעות באפליקציה |
| כמה נחתמו במקום | ההצעות המסומנות "נחתמה" |
| האם המוכר משתמש מעצמו | לשאול ולהסתכל על התאריכים ברשימה |
| מה חסר או מפריע | שיחה של 10 דקות עם המוכר בסוף כל שבוע |

## מגבלות ידועות בפיילוט

- **מכשיר אחד:** אין סנכרון בין מכשירים, ובעל העסק לא רואה הצעות של מוכר אחר. זה מגיע בשלב 2, עם שרת.
- **הקובץ ללקוח:** הלקוח מקבל טקסט בוואטסאפ, לא קישור או PDF. בטאבלט אפשר להדפיס או לשמור PDF מכפתור "הדפסה".
- **תמונות הקטלוג** שייכות לטלדור ולאלידור. האתר לא מופיע במנועי חיפוש, אבל כל מי שיש לו את הכתובת יכול לפתוח אותו. כדאי לקבל אישור מהספקים לפני שמרחיבים.
- **פרטיות:** פרטי הלקוחות נשמרים בטאבלט עצמו. אם הטאבלט הולך לאיבוד, הם הולכים איתו, ולכן כדאי לנעול אותו בקוד. לפני שעוברים לענן צריך מדיניות פרטיות ואבטחה לפי חוק הגנת הפרטיות.
